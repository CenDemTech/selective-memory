Chat Data Portability

Your conversations remain your property. Filter, redact, and export your chat history from any major LLM platform—all processed locally, entirely under your control.

Read the CDT Blog Visit Repo

What You Can Do

📤

Upload

Import JSON exports from Claude, ChatGPT/OpenAI, and Gemini conversations.

🔍

Review

Browse a searchable table of all conversations with metadata and transcript viewing.

🛡️

Redact

Remove sensitive text flagged by pattern-based scanning. Highlight problematic content before export.

✂️

Filter

Select which conversations to keep. Export only selected or remove selected conversations.

💾

Export

Download a clean, properly-formatted JSON file preserving the original structure.

🔐

Private

All processing happens on your machine. No data transmission to any server, ever.
